03 · Données

Ce qui se souvient · base de données

Je modélise avant de coder : schéma DBML, contraintes, index et migrations ordonnées. Easy Life compte 52 tables réparties en 9 schémas.

  • PostgreSQL
  • Redis
  • DBML
  • Migrations
Table trips {
  id bigint [pk]
  route_id bigint [ref: > routes.id]
  travel_class_id int [ref: > travel_classes.id]
  departs_at timestamptz [not null]

  indexes { (route_id, departs_at) }
}
